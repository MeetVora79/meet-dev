# Meet.dev — Developer Portfolio

A modern and fully responsive developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and modern UI/UX principles.

Designed to showcase projects, skills, GitHub activity, and professional experience with premium animations and scalable frontend architecture.

---

## ✨ Features

- Modern Premium UI/UX
- Fully Responsive Design
- Dark / Light Theme
- Smooth Scrolling Experience
- Animated Sections & Interactions
- Dynamic GitHub Repository Integration
- Professional Project Showcase
- Interactive Experience Section
- Contact Form with Email Integration
- Resume Download
- Mobile Optimized Navigation
- Performance-Focused Architecture

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Framer Motion

### UI / Animation
- GSAP
- Lenis Smooth Scroll
- React Icons
- Lucide React

### Integrations
- GitHub API
- EmailJS

## ⚡ Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/meet-dev.git
```

### Navigate to Project

```bash
cd meet-dev
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
